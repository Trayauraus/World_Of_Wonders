About

World O' Wonders is a 2D platformer created by Trayauraus / T-Man. It is built with the Godot Engine and features a charming pixel art style, challenging gameplay, and a world full of secrets to discover.

Custom Level Support

Take control of your experience! We've added an Import System located directly below the Play button in the main menu.

Supported Formats:

  • .wowlv – The official World O' Wonders custom level format.
  • .tscn – Godot scene files built for the game.

    • (Levels MUST be created in WoW Editor)
