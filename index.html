Custom Level Support

Take control of your experience! We've added an Import System located directly below the Play button in the main menu.

Supported Formats:

  • .wowlv – The official World O' Wonders custom level format (Exported to the game).
  • .tlst – Editor tileset saves (The editor utilizes two of these files: one for the main tileset, one for the background).
  • .dat – The main level data project file saved by the editor.

(Levels MUST be created in the WoW Editor)

Simply import your exported .wowlv files and dive into new worlds instantly.
